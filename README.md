# Multi-page Personal Portfolio (HTML5) - Rajat Kashyap

A responsive, multi-page personal portfolio website built with semantic **HTML5** and **CSS3**, version-controlled with **Git**, and hosted on **GitHub**.

---

## 📌 Project Overview
The **Multi-page Personal Portfolio** is designed to showcase an individual's background, education, technical skill sets, academic projects, and contact avenues across dedicated, interconnected web pages.

### 🎯 Key Objectives
- Master the fundamentals of web development and page structure.
- Implement HTML5 semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<figure>`).
- Establish cross-page navigation with interconnected hyperlinks.
- Practice industry-standard version control workflows using Git & GitHub.
- Deliver a responsive, clean, and accessible web application.

## 🌐 Features & Pages Breakdown

1. **Home (`index.html`)**
   - Personal introduction and greeting banner.
   - Call-to-action buttons ("View My Work", "Get In Touch").
   - Profile summary card with quick metrics.
   - Core highlights overview.

2. **About (`about.html`)**
   - Personal journey and software development philosophy.
   - Areas of interest and extracurricular passions.
   - Structured academic qualifications table using semantic `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`.

3. **Skills (`skills.html`)**
   - Frontend Web Technologies (HTML5, CSS3, JavaScript ES6+, Responsive Design).
   - Programming Languages (Python, C/C++, Java, SQL).
   - Developer Tools & Version Control (Git, GitHub, VS Code, CLI).
   - Professional Competencies (Problem Solving, Collaboration, Documentation).

4. **Projects (`projects.html`)**
   - Project cards using semantic `<article>` tags.
   - Key features, tech stack badges, and links to source code and live demos.
   - Covers: Multi-page Portfolio, Task Tracker App, Student Academic Portal, Weather Dashboard.

5. **Contact (`contact.html`)**
   - Direct contact channels: Email, Mobile, Location, and Social Links.
   - Semantic HTML5 form with validation (`<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>`, `<textarea>`, `<button>`).
   - Interactive submission confirmation message.

## 🏷️ HTML5 Semantic Elements Utilized

| Tag | Purpose in Portfolio |
|---|---|
| `<header>` | Page and site banners, top branding, navigation containers |
| `<nav>` | Primary site navigation bar across all pages |
| `<main>` | Unique, central content container for each specific page |
| `<section>` | Logical groupings of thematic content (Hero, Highlights, Skills categories) |
| `<article>` | Independent, self-contained cards (Skill cards, Project cards, Bio cards) |
| `<aside>` | Ancillary contact details and availability note |
| `<footer>` | Universal site footer with copyright, links, and social links |
| `<table>` | Structured academic education history on the About page |
| `<form>`, `<fieldset>`, `<legend>` | Accessible, semantic contact form structure |

## 🛠️ Git & GitHub Version Control Guide

Follow these commands in your terminal or PowerShell inside the project directory:

### Step 1: Initialize Git Repository
```bash
git init
```

### Step 2: Stage and Commit the Files
```bash
git add .
git commit -m "Initial commit: Multi-page Personal Portfolio with HTML5 semantic tags and responsive styling"
```

### Step 3: Link to Your GitHub Repository
1. Go to [GitHub.com](https://github.com/new) and create a new repository named `multi-page-portfolio`.
2. Link your local project to GitHub and push:
```bash
git branch -M main
git remote add origin https://github.com/rajat6822/multi-page-portfolio.git
git push -u origin main
```

---

## 🌍 Optional: Host Live on GitHub Pages (Bonus)

To get a live public website link:
1. In your GitHub repository, click **Settings**.
2. On the left sidebar, click **Pages**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**.
5. Your portfolio will be live at: `https://rajat6822.github.io/multi-page-portfolio/`
